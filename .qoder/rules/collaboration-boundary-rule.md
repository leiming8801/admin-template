# 协作边界规则

> **适用范围**：所有涉及界面验证的任务 + 所有临时文件生成
> **加载方式**：始终加载

---

## 一、页面验证边界

| # | 约束                                                                                                                                                         |
| :- | :----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1 | 写完页面 / 组件后，AI 只做静态检查：`pnpm type:check`、`pnpm build`、`pnpm lint`，并在回复末尾列出「需要你验证的点」                                              |
| 2 | 任何需要浏览器才能判断的事（打开页面、点击、截图、看布局 / 间距 / 配色、走交互流程）**必须先问用户**，得到同意后才执行                                          |
| 3 | 提问必须给三要素：验证哪个页面、做哪些操作、预计耗时与影响；用户拒绝时不得换方式（子代理、ComputerUse、curl 取页面）绕行                                        |
| 4 | 界面是否验收由用户决定；AI 的结论只能是「构建通过 / 类型检查通过」，不能是「页面显示正常」                                                                     |

---

## 二、临时文件落点

| # | 约束                                                                                                    |
| :- | :------------------------------------------------------------------------------------------------------ |
| 1 | 一切临时产物写入仓库根 `.tmp/`（已在 `.gitignore` 与 `.dockerignore` 中忽略），禁止散落在 `apps/`、`src/` 或仓库根 |
| 2 | 覆盖范围：一次性脚本（`*.mjs` / `*.ps1` / `*.py`）、截图录屏、构建与接口验证输出、导出的 `json` / `csv`、调试日志、临时备份 |
| 3 | 目录不存在时先创建：`New-Item -ItemType Directory -Force .tmp`（PowerShell）                            |
| 4 | 命名用 `.tmp/<任务>-<用途>.<ext>`，避免多任务互相覆盖                                                    |
| 5 | 任务结束时删除本次产生的临时文件；被忽略不等于可以不清理                                                |

---

## 禁令清单

| 禁止操作                                                     | 原因                                     | 正确做法                                       |
| :----------------------------------------------------------- | :--------------------------------------- | :--------------------------------------------- |
| 未询问就打开浏览器 / 派子代理 / 用 ComputerUse 验证页面       | 越界改动用户环境，且替代不了用户验收     | 先问，等用户拍板                               |
| 声称「页面已验证 / 显示正常」但没实际验证                     | 与 `intellectual-honesty-rule` 冲突      | 只报静态检查结论 + 待验证清单                  |
| 在 `apps/web/`、`src/`、仓库根直接写临时脚本（如 `check-icons.mjs`） | 污染工作区，易被误提交                   | 写到 `.tmp/`                                   |
| 把 `.tmp/` 改成不忽略、或提交 `!.tmp/xxx` 例外                | 破坏忽略约定，临时文件进版本库           | 整目录保持忽略，用时创建                       |
| 把真实源码 / 文档 / 配置放进 `.tmp/`                          | 被忽略后随清理丢失                       | 只有临时产物进 `.tmp/`                         |
