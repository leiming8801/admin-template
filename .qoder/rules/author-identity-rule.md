# 作者署名规则

> **适用范围**：任何需要填写 owner / 作者字段的场景（`.qoder` 规则与技能 frontmatter、文档顶部元数据）
> **加载方式**：按需加载（创建或修改资产、文档时读取）

---

## 核心规则

| # | 约束                                                                       |
| :- | :------------------------------------------------------------------------- |
| 1 | 作者 = 使用本机的当前用户，署名必须是一个真实的人；AI 只是执笔人           |
| 2 | 填 owner 前先查用户身份记忆：命中直接使用，不重复询问                       |
| 3 | 未命中时向用户询问一次真实姓名，获得后写入记忆供后续复用                   |
| 4 | 本机当前用户为 **雷敏**，新建资产与文档的 `owner` 直接填该姓名              |

---

## 姓名质量要求

| 要求     | 说明                                                     |
| :------- | :------------------------------------------------------- |
| 真实姓名 | 多人协作下署名须能直接对应到人                           |
| 禁止替代 | 昵称、花名、工号、Git/拼音账号名均不能作为 owner         |
| 禁止占位 | 不得填 TBD、模板名、他人姓名或留空                       |

---

## 写入位置

- 规则 / 技能资产：frontmatter 的 `owner` 字段
- 项目文档：文件顶部 HTML 注释的 `owner` 字段（`created` / `updated` 同步维护）

---

## 禁令清单

| 禁止操作                       | 原因                 | 正确做法                     |
| :----------------------------- | :------------------- | :--------------------------- |
| 记忆缺失时编造或沿用示例姓名   | 署名失真             | 询问一次后写入记忆           |
| 用 AI / Qoder / 工具名署名     | 作者必须是真实的人   | 填当前用户真实姓名           |
| 换人使用同一台机器仍沿用旧署名 | 张冠李戴             | 检测到用户变更时重新确认     |
