# 文档组织约束

> **适用范围**：本仓 `docs/` 下的项目文档（架构、模块、数据库、部署、国际化等）
> **不适用**：`.qoder/` 下的规则与技能资产；代码内注释
> **加载方式**：按需加载（新增 / 移动 / 改写文档时读取）

---

## 目录与命名

现状是 10 篇平铺 + 一份索引，不强制改造存量，但增量遵守：

| 情况                        | 做法                                                          |
| :-------------------------- | :------------------------------------------------------------ |
| 单篇、主题独立              | 直接平铺 `docs/<主题>.md`（如 `部署与运维指南.md`）           |
| 同一主题预计 ≥2 篇          | 建主题目录 `docs/<主题>/`，入口为 `docs/<主题>/README.md`      |
| 文件名                      | 中文主题名，与内容一致，不用 `temp/`、`杂项/`、`其他/`、无主题目录 |
| 一次性产物（截图/日志/导出）| 不放 `docs/`，用完即删或留在工作区外                            |

---

## 索引同步（强制）

- `docs/README.md` 是唯一索引：新增、改名、移动文档时**同一次改动内**更新索引
- 改完 grep 旧文件名 / 旧路径必须零命中（含 AGENTS.md、其他文档互链）

---

## 开发文档单文档全生命周期

一份改造 / 开发文档从头写到完工，不拆"实施计划"：

| 阶段       | 形态                                                                                       |
| :--------- | :----------------------------------------------------------------------------------------- |
| 施工前     | 背景 / 改动范围 / 现状速览 / 设计细节 / 实施步骤 / 自测清单；头部标 `状态：施工中`          |
| 完工时     | 同一份文件改 `状态：已完成（日期）`；删除实施步骤，回收 TODO，自测清单填成验收记录，补差异与根因 |

---

## 文档元数据与同步

| 场景                         | 约束                                                                     |
| :--------------------------- | :----------------------------------------------------------------------- |
| 文档顶部元数据               | HTML 注释写 `owner / created / updated`，`owner` 为真实姓名（`author-identity-rule`），改正文必须同步 `updated` |
| 上游仓 / 外部系统的需求或接口契约 | 只读，只允许上游 → 本地的**向下同步**；禁止回写上游                           |
| 文档描述与代码不一致         | 以代码为准做最小修正，流程见技能 `doc-sync-skill`，禁止整文件覆盖重写        |
| 契约与实现冲突（代码可能有问题） | 不擅自改文档迁就代码，单列"待确认"交用户裁决                            |

---

## 禁令清单

| 禁止操作                                 | 原因                             | 正确做法                          |
| :--------------------------------------- | :------------------------------- | :-------------------------------- |
| 新增文档不改 `docs/README.md`            | 出现幽灵文档，人和 AI 都找不到   | 同一次改动内更新索引              |
| 移动文档后不搜旧路径引用                 | 其他文档、AGENTS.md 出现死链     | grep 旧路径改齐后再提交           |
| 把未验证的设计写成"已完成"               | 造成假完成                       | 状态如实标注，TODO 显式保留       |
| 同一事实在 README / AGENTS.md / docs 三处各写一份 | 改一处漏一处               | 定一个 SSOT，其他位置改为链接     |
| 用截图 / 日志 / 导出临时文件充当文档     | 不可检索、易过期                 | 结论写文字，产物不入库            |
