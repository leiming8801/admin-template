# 共享类型包说明

> 本文档说明 `@admin-template/shared` 包的类型定义、引用方式与修改约定。

## 1. 包概览

| 属性 | 值 |
|---|---|
| 包名 | `@admin-template/shared` |
| 路径 | `packages/shared/` |
| 语言 | TypeScript 5.4+ |
| 编译 | `tsc` → `dist/` |
| 引用方 | `apps/server`（引用 dist）、`apps/web`（引用源码） |

## 2. 文件结构

```
packages/shared/
├── package.json          # 包定义
├── tsconfig.json         # TypeScript 配置
└── src/
    ├── index.ts           # 统一导出（re-export 所有模块）
    ├── common.ts          # 通用类型：ApiResponse / PageQuery / PageResult / 枚举
    ├── auth.ts            # 认证类型：LoginResult / UserProfile / MenuItem
    ├── system.ts          # 系统管理类型：AdminUser / Role / Permission 及 DTO
    ├── member.ts           # 会员管理类型：Member 及 DTO
    └── dashboard.ts        # 工作台类型：DashboardStats
```

## 3. 引用方式

### 3.1 前端引用（源码直接引用）

文件路径：`apps/web/config/vite.config.base.ts`

```typescript
resolve: {
  alias: [
    {
      find: '@admin-template/shared',
      replacement: resolve(__dirname, '../../packages/shared/src/index.ts'),
    },
  ],
}
```

前端通过 Vite alias 直接引用 shared 源码，**无需编译**，修改即时生效。

```typescript
// 前端代码中直接 import
import { MenuItem, LoginResult, UserProfile } from '@admin-template/shared';
```

### 3.2 后端引用（引用编译产物）

文件路径：`apps/server/package.json`

```json
{
  "dependencies": {
    "@admin-template/shared": "workspace:*"
  }
}
```

后端通过 pnpm workspace 引用，使用编译后的 `dist/` 产物：

```json
// packages/shared/package.json
{
  "main": "./dist/index.js",
  "types": "./dist/index.d.ts"
}
```

```typescript
// 后端代码中 import
import { LoginResult, UserProfile, MenuItem, RefreshTokenResult } from '@admin-template/shared';
```

**重要**：修改 shared 类型后，需执行 `pnpm build`（shared 包）使后端生效。前端 Vite 热更新自动生效。

## 4. 类型定义详解

### 4.1 common.ts — 通用类型

文件路径：`packages/shared/src/common.ts`

```typescript
/** 统一 API 响应结构 */
export interface ApiResponse<T = any> {
  code: number;      // 业务状态码（200=成功）
  message: string;   // 消息（成功='success'，失败=翻译后文案）
  data: T;           // 业务数据
}

/** 分页查询参数 */
export interface PageQuery {
  page: number;
  pageSize: number;
}

/** 分页响应结构 */
export interface PageResult<T> {
  list: T[];
  total: number;
  page: number;
  pageSize: number;
}

/** 通用状态枚举 */
export enum StatusEnum {
  DISABLED = 0,
  ENABLED = 1,
}

/** 权限类型枚举 */
export enum PermissionTypeEnum {
  MENU = 1,    // 菜单
  BUTTON = 2,  // 按钮
  API = 3,     // API
}
```

### 4.2 auth.ts — 认证类型

文件路径：`packages/shared/src/auth.ts`

```typescript
/** 登录请求 */
export interface LoginRequest {
  username: string;
  password: string;
}

/** 登录响应 */
export interface LoginResult {
  accessToken: string;
  refreshToken: string;
  expiresIn: number;   // accessToken 有效期（秒）
}

/** 刷新 Token 请求 */
export interface RefreshTokenRequest {
  refreshToken: string;
}

/** 刷新 Token 响应 */
export interface RefreshTokenResult {
  accessToken: string;
  refreshToken: string; // 每次刷新同时轮换，调用方必须替换旧值
  expiresIn: number;
}

/** 更新当前用户资料请求 */
export interface UpdateProfileRequest {
  nickname: string;
}

/** 修改当前用户密码请求 */
export interface UpdatePasswordRequest {
  oldPassword: string;
  newPassword: string;
}

/** 当前登录用户信息 */
export interface UserProfile {
  id: number;
  username: string;
  nickname: string;
  avatar?: string;
  roles: string[];         // 角色编码列表
  permissions: string[];   // 权限码列表
}

/** 动态菜单项 */
export interface MenuItem {
  id: number;
  /** i18n key（如 "menu.system.adminUser"），前端用 t() 翻译，无翻译时显示原文 */
  name: string;
  path: string;
  component?: string;    // 前端组件路径（如 "system/admin-user/index"）
  icon?: string;
  children?: MenuItem[];
}
```

### 4.3 system.ts — 系统管理类型

文件路径：`packages/shared/src/system.ts`

```typescript
import { PermissionTypeEnum } from './common';

/** 后台管理员用户 */
export interface AdminUser {
  id: number;
  username: string;
  nickname: string;
  email?: string;
  phone?: string;
  avatar?: string;
  status: number;            // 0=禁用 1=启用
  lastLoginAt?: string;
  lastLoginIp?: string;
  remark?: string;
  roles: Role[];
  createdAt: string;
  updatedAt: string;
}

/** 创建/编辑后台用户的 DTO */
export interface AdminUserDto {
  username: string;
  password?: string;
  nickname: string;
  email?: string;
  phone?: string;
  avatar?: string;
  status: number;
  remark?: string;
}

/** 角色 */
export interface Role {
  id: number;
  name: string;
  code: string;
  sort: number;
  status: number;
  remark?: string;
  createdAt: string;
  updatedAt: string;
}

/** 管理员用户简要信息（用于角色列表展示绑定用户） */
export interface AdminUserBrief {
  id: number;
  username: string;
  nickname: string;
}

/** 角色列表项（含绑定用户信息） */
export interface RoleListItem extends Role {
  users: AdminUserBrief[];
}

/** 创建/编辑角色的 DTO */
export interface RoleDto {
  name: string;
  code?: string;      // 留空时由系统自动生成
  sort?: number;
  status?: number;
  remark?: string;
}

/** 权限（菜单/按钮/API，树形结构） */
export interface Permission {
  id: number;
  parentId: number;
  /** 权限名称，存 i18n key */
  name: string;
  type: PermissionTypeEnum;
  /** 权限标识（如 "system:user:add"） */
  permission?: string;
  /** 前端路由路径（菜单类型） */
  path?: string;
  /** 前端组件路径（菜单类型） */
  component?: string;
  /** 菜单图标 */
  icon?: string;
  sort: number;
  visible: number;    // 0=隐藏 1=显示
  children?: Permission[];
  createdAt: string;
  updatedAt: string;
}

/** 创建/编辑权限的 DTO */
export interface PermissionDto {
  parentId: number;
  name: string;
  type: PermissionTypeEnum;
  permission?: string;
  path?: string;
  component?: string;
  icon?: string;
  sort?: number;
  visible?: number;
}

/** 分配角色给用户的 DTO */
export interface AssignRolesDto {
  roleIds: number[];
}

/** 分配权限给角色的 DTO */
export interface AssignPermissionsDto {
  permissionIds: number[];
}

/** 重置密码的 DTO */
export interface ResetPasswordDto {
  password: string;
}

/** 修改状态的 DTO */
export interface UpdateStatusDto {
  status: number;
}
```

## 5. 修改约定

### 5.1 新增类型

1. 在对应模块文件中添加类型定义（如 `system.ts`）
2. 如果是新模块，创建新文件并在 `index.ts` 中 `export *`
3. 执行 `pnpm build`（shared 包）编译，使后端生效
4. 前端无需额外操作（Vite alias 直接引用源码）

### 5.2 修改现有类型

1. 修改 `packages/shared/src/` 中的类型定义
2. **同步检查后端 Service / Controller** 的返回类型是否匹配
3. **同步检查前端 API / Store** 的类型引用是否匹配
4. 执行 `pnpm build`（shared 包）使后端生效

### 5.3 枚举使用

`StatusEnum` 和 `PermissionTypeEnum` 在前后端均可使用：

```typescript
// 后端
import { PermissionTypeEnum } from '@admin-template/shared';
if (permission.type === PermissionTypeEnum.MENU) { ... }

// 前端
import { PermissionTypeEnum, StatusEnum } from '@admin-template/shared';
const statusLabel = member.status === StatusEnum.ENABLED ? '启用' : '禁用';
```

## 6. 类型与后端 DTO 的关系

后端的 DTO（class-validator 装饰的类）在 `apps/server/src/modules/*/dto/` 中定义，与 shared 包的 interface 对应但不完全相同：

| shared 包（interface） | 后端 DTO（class） | 差异 |
|---|---|---|
| `AdminUserDto` | `CreateAdminUserDto` / `UpdateAdminUserDto` | 后端 DTO 有 class-validator 装饰器（@IsString, @IsOptional 等），按操作类型拆分 |
| `RoleDto` | `CreateRoleDto` / `UpdateRoleDto` | 同上 |
| `PermissionDto` | `CreatePermissionDto` / `UpdatePermissionDto` | 同上 |
| `MemberDto` | `UpdateMemberDto` | 同上 |

**设计原则**：shared 包定义的是接口契约（前后端共享），后端 DTO 是实现层（含校验逻辑），前端使用 shared 包的类型即可。
